This workshop introduces *Automated tool-calling evaluation-data generation for custom MCP servers*:
the EvalHub MCP server and agent skills that let AI coding agents discover evaluation providers,
submit jobs, and interpret results through tool-calling on Red Hat OpenShift AI.

**What you will learn:**

* How EvalHub, its providers, and the MCP server fit into RHOAI 3.5 evaluation workflows
* Deploy the EvalHub MCP server through the TrustyAI Operator and register it with an AI coding agent
* Generate evaluation data through automated tool calls: `discover_providers`, `submit_evaluation`, and `get_job_status`
* Make custom providers agent-discoverable with agent metadata and generate auditable evaluation cards

== Prerequisites

* RHOAI operator installed
* MCP server deployed
* An OpenShift cluster with RHOAI 3.5 installed
* The TrustyAI component in your `DataScienceCluster` set to `Managed`, with EvalHub deployed by the TrustyAI Operator
* An MCP client such as Claude Code installed on your workstation
