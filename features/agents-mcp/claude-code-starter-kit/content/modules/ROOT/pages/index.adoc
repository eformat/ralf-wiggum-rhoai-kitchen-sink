This workshop introduces the *Claude Code agent starter kit* — a Developer Preview
feature that lets you deploy and configure the Anthropic Claude Code agent on OpenShift
AI using a pre-configured Containerfile and Kustomize deployment manifests.

**What you will learn:**

* What the Claude Code agent starter kit provides and where it fits in RHOAI 3.5
* The three validated inference paths: direct Anthropic API, self-hosted models through vLLM, and vLLM through the OGX gateway
* How skills and MCP server configurations are injected at deploy time through a ConfigMap
* What the built-in MLflow tracing integration captures about agent behavior
* How the kit runs under the OpenShift restricted-v2 SCC with workspace storage that persists across pod restarts

== Prerequisites

* RHOAI operator installed
* Anthropic API access

[NOTE]
====
Anthropic API access is only required for the direct Anthropic inference path. The
vLLM-based paths let you use your own models without an Anthropic subscription.
====

* An OpenShift cluster with RHOAI 3.5 installed
