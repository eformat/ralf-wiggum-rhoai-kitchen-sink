This workshop introduces *External metering integration for MaaS*, a Developer Preview
feature that connects Models-as-a-Service (MaaS) inference traffic to an external metering
or billing system by using Backend-Based Routing (BBR) plugins. With this integration,
platform operators running MaaS as a commercial AI service can capture per-request token
usage and enforce token budgets through an external metering system.

**What you will learn:**

* How the post-inference token usage webhook and pre-inference credit check BBR plugins capture and enforce token usage
* What the emitted token usage event contains and where it flows
* How to verify the MaaS foundation (published models, subscriptions, authorization policies) that metering builds on

== Prerequisites

* RHOAI operator installed
* MaaS enabled
* An OpenShift cluster with RHOAI 3.5 installed
* Recommended prerequisite: complete the xref:maas-core::index.adoc[Models-as-a-Service (MaaS) core: access model and token mechanism] workshop first
