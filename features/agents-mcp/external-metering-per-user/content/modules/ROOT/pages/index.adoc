This workshop is a guided tour of *External metering: per-user token usage and
cost* in RHOAI 3.5: an external metering IPP plugin and a standalone metering
service that let platform operators track per-user and per-model token
consumption, attribute costs, enforce quotas, and generate chargeback reports
for inference requests passing through the AI Inference Gateway.

Because this is a Developer Preview feature, this workshop focuses on
understanding the architecture and exploring the usage-data surfaces that
already exist in your cluster rather than on installing new components.

**What you will learn:**

* What the external-metering IPP plugin and the standalone metering service do and where they fit in RHOAI 3.5
* How the plugin chain checks user balances and extracts token usage from OpenAI and Anthropic provider responses
* How CloudEvents flow to the PostgreSQL-backed metering service for aggregation and cache-aware pricing
* Where per-user usage data appears in the MaaS observability dashboard and how it differs from the CSV showback export

== Prerequisites

* An OpenShift cluster with RHOAI 3.5 installed
* RHOAI operator installed
* MaaS enabled
* External metering configured
* Recommended prerequisite: complete the xref:maas-core::index.adoc[Models-as-a-Service (MaaS) core: access model and token mechanism] workshop first
