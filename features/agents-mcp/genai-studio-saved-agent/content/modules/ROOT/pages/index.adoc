This workshop introduces *Gen AI Studio saved-agent configuration*: saving a
Gen AI Studio playground setup — model selection, inference parameters, MLflow
prompt reference, RAG knowledge sources, and MCP server connections — as a
single named, reusable agent scoped to your project namespace.

**What you will learn:**

* What a saved agent captures (and what it does not) and where agents are stored
* Enable the `agentConfigManagement` dashboard feature flag in the `OdhDashboardConfig` custom resource
* Save, load, variant-copy, rename, and delete agents from the playground header menu and the Agents tab under *Gen AI studio → AI asset endpoints*

== Prerequisites

* RHOAI operator installed
* Gen AI Studio accessible
* A project with a configured playground and at least one model selected
* The MLflow service available in your project (saved agents reference MLflow prompts)
* Cluster administrator privileges to enable the feature flag
* An OpenShift cluster with RHOAI 3.5 installed
