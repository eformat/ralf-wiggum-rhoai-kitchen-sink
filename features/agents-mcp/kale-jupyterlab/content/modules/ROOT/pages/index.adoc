This workshop introduces *Kale JupyterLab extension*.

**What you will learn:**

* What the Kale JupyterLab extension does and where it fits in RHOAI 3.5
* Which workbench images ship Kale and how to enable the extension in your workbench
* How to turn on Kale for a notebook and use the Kale metadata editor
* Where the converted pipeline, runs, and artifacts live in the OpenShift AI dashboard

== Prerequisites

* RHOAI operator installed
* A workbench based on one of the default data science notebook images (Standard Data Science, PyTorch, TensorFlow, TrustyAI, ROCm-PyTorch, ROCm-TensorFlow)
* Pipelines enabled, with a Data Science Pipelines Application deployed in the same namespace as the workbench
* An OpenShift cluster with RHOAI 3.5 installed
