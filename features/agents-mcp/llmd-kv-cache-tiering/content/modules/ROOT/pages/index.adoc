This workshop introduces *Hierarchical KV Cache Tiering (llm-d)*: a Developer
Preview feature that lets platform operators serve more concurrent users on the
same GPU footprint by automatically placing KV cache entries on the tiers they
configure, increasing effective cache size and prefix-cache reuse for multi-turn
and long-context workloads.

**What you will learn:**

* What hierarchical KV cache tiering does and where it fits in RHOAI 3.5
* How the llm-d Endpoint Picker routes requests for KV cache reuse with its default 2:2:3:2 scorer profile
* How to recognize, select, and verify a KV-cache-aware router configuration
* Which `llm_d_epp_` metrics reveal KV cache utilization and prefix cache hit behavior
