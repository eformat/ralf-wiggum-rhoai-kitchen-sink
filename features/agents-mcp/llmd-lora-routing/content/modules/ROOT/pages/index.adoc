This workshop introduces *LoRA-aware routing for llm-d*: a Developer Preview
feature that lets platform operators route inference requests to pods where the
target LoRA adapter is already loaded, avoiding the cold-load latency of
on-demand adapter swaps. When no pod with the target adapter is available,
requests automatically fall back to standard routing.

**What you will learn:**

* What LoRA-aware request routing does and the cold-load latency problem it solves
* How the llm-d Endpoint Picker and router configurations expose adapter-aware routing in RHOAI 3.5
* How to walk the advanced routing workflow of the model deployment wizard
* Which `llm_d_epp_` request metrics reveal adapter-targeted routing and fallback behavior
