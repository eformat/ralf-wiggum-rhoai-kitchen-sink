This workshop introduces the *MCP gateway Operator* — the Red Hat Connectivity
Link feature that connects and secures your backend Model Context Protocol
(MCP) servers to your frontend agentic AI services behind a single endpoint.

**What you will learn:**

* What the MCP gateway does and where it fits in RHOAI 3.5 and Connectivity Link
* Install the MCP gateway Operator with OLM and deploy a gateway with a Gateway object, MCP listener, and `MCPGatewayExtension` CR
* Register backend MCP servers with HTTPRoute and `MCPServerRegistration` CRs and verify tool discovery with `curl`
* Curate tools into a virtual MCP server with an `MCPVirtualServer` CR

== Prerequisites

* RHOAI operator installed
* MCP Lifecycle Operator enabled
* An OpenShift cluster with RHOAI 3.5 installed
* Red Hat Connectivity Link 1.4.1 or later installed
