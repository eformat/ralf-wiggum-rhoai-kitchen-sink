This workshop takes a guided tour of *MiDojo*, the man-in-the-middle
adversarial testing execution engine for AI agents — a Developer Preview
feature of RHOAI 3.5.

**What you will learn:**

* What MiDojo does and why it injects attack payloads at the tool layer
* The anatomy of a declarative YAML scenario: environment state, tasks, and injection vectors
* How MiDojo grades task completion (utility) and attack resistance (security) from the full tool trace
* The building blocks of a testing session: custom external suites, the MiniBank reference suite, pluggable backends, and supported agent protocols

== Prerequisites

* An OpenShift cluster with RHOAI 3.5 installed
* RHOAI operator installed
* Model serving endpoint
