This workshop introduces *OGX-native agentic API surface (Tool Runtime, Responses, Conversations)*.

**What you will learn:**

* What the OGX agentic API surface is: native OGX APIs (Tool Runtime) versus the OpenAI-compatible surface (Responses, Conversations)
* Deploy an OGXServer and verify it reaches the Running phase
* Connect an OpenAI SDK client to the OGX route and drive multi-turn, stateful chats with the Conversations API
* Ground answers in your documents with the `file_search` tool and inspect `file_citation` annotations
* Opt into Responses API guardrails and survey the Tool Runtime API support level

== Prerequisites

* RHOAI operator installed
* OGX enabled
* An OpenShift cluster with RHOAI 3.5 installed
