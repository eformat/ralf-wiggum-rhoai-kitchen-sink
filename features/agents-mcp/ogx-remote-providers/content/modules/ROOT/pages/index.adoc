This workshop introduces *OGX remote::anthropic and remote::gemini providers* —
remote inference providers that proxy OpenAI-compatible requests from OGX to
the Anthropic and Google Gemini APIs.

**What you will learn:**

* Where `remote::anthropic` and `remote::gemini` fit in the OGX API provider support table
* How provider enablement works: enablement variables, the OGX `config.yaml`, and Secrets-backed credential injection
* How to store an API key in a Secret, enable a remote provider, and call the remote model through the OpenAI-compatible `/v1` surface

== Prerequisites

* RHOAI operator installed
* OGX enabled
* External API keys
* An OpenShift cluster with RHOAI 3.5 installed
