This workshop introduces the *OpenClaw agent starter kit* — a Developer Preview
feature that lets you deploy and manage OpenClaw, an open-source general-purpose
agent, on Red Hat OpenShift AI using validated Kustomize manifests and an
automated installer that manages runtime concerns and optimizes workspace
persistence.

**What you will learn:**

* What OpenClaw is and what the starter kit provides in RHOAI 3.5
* The two deployment options: validated Kustomize manifests or the automated OpenClaw installer
* How the agent connects to self-hosted models through vLLM via the OGX inference gateway with an OpenAI-compatible API
* What the diagnostics-otel plugin captures in MLflow: model calls, tool executions, and context assembly spans
* How browser-based access control is enforced with the OAuth proxy backed by OpenShift RBAC
* How the kit maintains workspace storage across pod restarts and runs under the restricted-v2 SCC
* How to validate your environment with the included model compatibility matrix and troubleshooting guide

== Prerequisites

* RHOAI operator installed
* An OpenShift cluster with RHOAI 3.5 installed
