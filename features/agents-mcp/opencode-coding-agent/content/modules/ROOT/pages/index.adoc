This workshop introduces *OpenCode coding-agent deployment* on Red Hat OpenShift
AI. OpenCode is an open-source, terminal-based coding agent. In RHOAI 3.5 it is
the first coding agent validated to follow the onboarding pattern established by
OpenClaw: the validation confirms that agent platform operators, vLLM and OGX
(formerly Llama Stack) inference backends, and MLflow tracing integration
successfully generalize to coding-specific workloads.

**What you will learn:**

* What OpenCode does, its Technology Preview status in RHOAI 3.5, and what the validation provides (supported container images, operator-managed deployment manifests, verified inference backend interoperability, MLflow tracing integration)
* The onboarding pattern OpenCode follows, from validated Kustomize manifests to OpenAI-compatible inference backends (vLLM and the OGX gateway)
* How to verify that your workshop environment is ready: RHOAI operator status and an available LLM serving endpoint
* How to probe an OpenAI-compatible endpoint and explore the console surfaces that back the agent (external model endpoints, workbench IDE terminal, MLflow tracing)

== Prerequisites

* RHOAI operator installed
* LLM serving endpoint available
* An OpenShift cluster with RHOAI 3.5 installed
