This workshop introduces *Validated tool-calling configuration in Model Catalog*.
The model catalog displays validated vLLM deployment arguments for models with
confirmed tool-calling support, so you can run a model with tool calling enabled
the first time, without guessing at runtime arguments.

**What you will learn:**

* What validated tool-calling configuration does and where it fits in RHOAI 3.5
* How to enable the feature with the `spec.dashboardConfig.toolCalling` flag in the `OdhDashboardConfig` custom resource
* How to find and copy the exact `vllm serve` arguments from the Validated Arguments section and Tool Calling panel on a model details page
* How to validate a model's tool-calling accuracy on your own MCP tools with the SDG Hub MCP evaluation pipeline

== Prerequisites

* An OpenShift cluster with RHOAI 3.5 installed
* Cluster administrator access (required to update the `OdhDashboardConfig` custom resource)
* The model catalog accessible, with the model registry component enabled
* For Module 02: one or more development or staging MCP servers, and access to an OpenAI API-compatible frontier LLM endpoint for teacher and judge models
