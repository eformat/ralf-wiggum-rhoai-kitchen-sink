This workshop introduces *View running agent deployments in dashboard*.

**What you will learn:**

* What the Agent Ops view shows: running agent deployments listed directly in the RHOAI dashboard, including agents deployed manually as OpenShell-managed Sandbox custom resources
* Check and enable the `agentOps` dashboard feature flag in the `OdhDashboardConfig` custom resource
* Tour the list's name and status columns, namespace scoping, and filtering — then trace the Sandbox CRs behind it with the CLI

== Prerequisites

* RHOAI operator installed
* Agent deployment running
* An OpenShift cluster with RHOAI 3.5 installed
