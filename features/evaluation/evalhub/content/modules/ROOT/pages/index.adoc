This workshop introduces *Evaluation Stack (EvalHub)*, the evaluation
orchestration service for LLMs on Red Hat OpenShift AI.

**What you will learn:**

* What EvalHub does and how its server, SDK/CLI, and providers fit together
* Verify the EvalHub deployment with the TrustyAI Operator and its tenant resources
* Submit evaluation jobs against benchmarks and custom collections from the CLI, the REST API, and the RHOAI dashboard
* Track jobs and results, log metrics to MLflow, and grant tenant access with RBAC

== Prerequisites

* RHOAI operator installed, with the TrustyAI component set to `Managed` and KServe in `RawDeployment` mode
* Model serving endpoint with an OpenAI-compatible `/v1` API
* An OpenShift cluster with RHOAI 3.5 installed, EvalHub deployed, and your project registered as a tenant
* Python 3.11 or later with access to PyPI for the EvalHub SDK and CLI
