*AutoRAG* is an automated optimization system in Red Hat OpenShift AI that finds
the best retrieval-augmented generation (RAG) configuration for your documents
and use case. You provide documents and a test data file. AutoRAG tests
combinations of chunking, embedding, retrieval, and generation settings, ranks
the resulting RAG patterns on a leaderboard by evaluation metrics, and generates
Jupyter notebooks you can use to run the best pattern.

**What you will learn:**

* What AutoRAG does, how its optimization workflow works, and what the Technology Preview limitations are
* How to prepare a JSON test data file with questions, expected answers, and document IDs
* How to create an AutoRAG optimization run in the two-step wizard (optimization metric, run preset, and model selection)
* How to evaluate the leaderboard, pattern details, and Sample Q&A results to pick the best pattern
* How to run the winning pattern in a workbench with the generated indexing and inference notebooks

== Prerequisites

* RHOAI operator installed
* OGX enabled and configured with foundation and embedding models
* A pipeline server in your project with *Enable AutoML and AutoRAG pipelines* selected
* A remote vector database (Milvus or pgvector) registered as a vector I/O provider with your OGX instance
* Documents in PDF, DOCX, PPTX, Markdown, HTML, or TXT format
