This workshop introduces the *Feature Store (Feast-based)* — a centralized repository that
stores, manages, and serves machine learning features for both training and inference.

**What you will learn:**

* What Feature Store does and where it fits in RHOAI 3.5: registry, offline store, online store, and feature servers
* How to enable the Feast operator in the Data Science Cluster and deploy a `FeatureStore` instance
* How to define, apply, and materialize features with the `feast` CLI and retrieve them with the Python SDK
* How to connect workbenches to a Feature Store instance from the dashboard
* How to tune and scale Feature Store for production: online store settings, workers, replicas, and HPA

== Prerequisites

* An OpenShift cluster with RHOAI 3.5 installed
* The RHOAI operator installed and `cluster-admin` access for the DSC configuration step
* A working project for your Feature Store instance
* `oc` CLI logged in to your cluster (see xref:getting-connected.adoc[])
