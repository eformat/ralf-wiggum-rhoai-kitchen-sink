This workshop introduces *NeMo Guardrails* — the AI safety framework in RHOAI
that controls LLM input and output with rails for sensitive data detection,
content filtering, and custom validation rules, deployed through the TrustyAI
Operator.

**What you will learn:**

* How NeMo Guardrails works and how the TrustyAI Operator deploys it from a `NemoGuardrails` custom resource
* Deploy a standalone guardrails service with built-in Presidio and regex detectors — no LLM required
* Test rails with `/v1/guardrail/checks` and front a live model with `/v1/chat/completions`
* Switch guardrail policies with `config_id`, mask PII instead of blocking, and add custom rails with Python actions

== Prerequisites

* An OpenShift cluster with RHOAI 3.5 installed, and you are logged in
* The TrustyAI component set to `Managed` in your DataScienceCluster (DSC)
* Cluster administrator permissions, or permissions to create ConfigMaps and `NemoGuardrails` resources in your project
* For module 2 (Exercise 3) and module 3: a model deployed on the model-serving platform
