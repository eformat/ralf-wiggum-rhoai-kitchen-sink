Models-as-a-Service (MaaS) is the governance layer that sits between your users
and model serving infrastructure in Red Hat OpenShift AI. Instead of handing out
service-account tokens, users discover governed models, authenticate with
subscription-bound API keys, and consume OpenAI-compatible endpoints under
per-group token quotas.

**What you will learn:**

* How the MaaS access model works: registered models (`MaaSModelRef`), subscriptions (`MaaSSubscription`), and authorization policies (`MaaSAuthPolicy`)
* How to find MaaS-published models in the dashboard and generate your own API key
* How to call governed models through the OpenAI-compatible gateway and read token usage and rate-limit responses
* How administrators create subscriptions and authorization policies, revoke keys, and monitor token consumption

== Prerequisites

* RHOAI operator installed
* MaaS enabled
* An OpenShift cluster with RHOAI 3.5 installed
* A model published to MaaS with your group assigned to a subscription (your
facilitator provides this; module 03 covers the administrator steps)
