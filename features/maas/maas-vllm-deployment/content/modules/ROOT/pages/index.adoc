This workshop introduces *vLLM model deployment directly through MaaS*.

**What you will learn:**

* How vLLM-served models reach the MaaS gateway in RHOAI 3.5 and what Technology Preview means for this feature
* Enable the vLLM deployment on MaaS flag and verify the MaaS platform components
* Deploy a vLLM model with the dashboard wizard and publish it to MaaS
* Grant group access with MaaSSubscription and MaaSAuthPolicy resources and call the OpenAI-compatible MaaS endpoint

== Prerequisites

* RHOAI operator installed
* MaaS enabled
* Cluster administrator access for the dashboard flag patch and group creation
* An OpenShift cluster with RHOAI 3.5 installed
