This workshop introduces *Model registry and model catalog* — the curated
library where you discover and evaluate gen AI models, and the central
repository where you register, version, and manage their lifecycle before
deployment.

**What you will learn:**

* How the Model Catalog and Model Registry fit together in the RHOAI model lifecycle
* Enable the `modelregistry` component in the DataScienceCluster and create a model registry as an administrator
* Register models and versions from the registry and the model catalog, and grant registry access
* Store models as OCI ModelCar images, monitor transfer jobs, and govern model catalog sources

== Prerequisites

* RHOAI operator installed
* Model registry enabled in DSC (Module 01 walks through the enablement)
* An OpenShift cluster with RHOAI 3.5 installed
