This workshop introduces *Distributed Inference with llm-d: priority-based flow control*.

**What you will learn:**

* How the flow control layer of the Endpoint Picker (EPP) manages priority-based queuing, saturation detection, and load shedding for llm-d inference
* How to enable the `flowControl` feature gate and configure a saturation detector on an `LLMInferenceService`
* How to define priority tiers with `InferenceObjective` resources and configure fairness policies and per-band capacity limits
* How to validate priority differentiation, rejection behavior, and flow control metrics under load

== Prerequisites

* RHOAI operator installed
* Distributed Inference with llm-d deployed
* An OpenShift cluster with RHOAI 3.5 installed
* Recommended prerequisite: complete the xref:llmd-core::index.adoc[Distributed Inference with llm-d (core)] workshop first
