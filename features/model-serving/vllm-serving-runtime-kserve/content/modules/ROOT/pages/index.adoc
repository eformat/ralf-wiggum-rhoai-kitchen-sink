This workshop introduces *vLLM ServingRuntime for KServe*.

**What you will learn:**

* What the vLLM ServingRuntime for KServe is and how the `ServingRuntime` and `InferenceService` CRDs fit together on the single-model serving platform
* Enable the model serving platform and the vLLM ServingRuntime for KServe from the console and verify it from the CLI
* Deploy a generative AI model through the *Deploy model* wizard and inspect the generated `InferenceService` CR
* Query the deployed model over its OpenAI-compatible REST API with token authentication

== Prerequisites

* RHOAI operator installed
* KServe enabled
* An OpenShift cluster with RHOAI 3.5 installed
* A project with a connection to model storage (S3-compatible object storage)
* An NVIDIA GPU hardware profile (vLLM requires GPU support enabled and the Node Feature Discovery Operator configured)
