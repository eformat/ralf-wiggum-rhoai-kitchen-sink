= RHOAI 3.5 Kitchen Sink: Feature Workshop Catalog

Welcome to the RHOAI Kitchen Sink — a hands-on workshop for *every active feature* in
Red Hat OpenShift AI 3.5, organized by category with maturity badges.

*New to the catalog?* Start with a curated xref:learning-paths.adoc[Learning Path] —
ordered chains of workshops, from serving LLMs to governing the platform.

*Setting up the workshop cluster?* See xref:cluster-setup.adoc[Cluster Setup] —
the kustomize `cluster/` config and which overlays each lab needs.

**Maturity legend:**

* *GA* — Generally Available; fully supported, production-ready exercises
* *TP* — Technology Preview; functional but not supported with production SLAs
* *DP* — Developer Preview; provided as-is for evaluation
