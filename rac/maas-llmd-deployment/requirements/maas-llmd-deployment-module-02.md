# Module 02: Hands-on Exercise

## Problem

A published model is not yet accessible to users: both a `MaaSSubscription`
(token rate limits) and a `MaaSAuthPolicy` (gateway access) are required before
the MaaS gateway serves it. Learners must create both governance resources,
generate a subscription-scoped API key, and prove end-to-end access through the
MaaS gateway with the OpenAI-compatible API.

## Requirements

- [REQ-021] Learner MUST be able to apply a `MaaSSubscription` (owner groups, model refs, `tokenRateLimits`) and a `MaaSAuthPolicy` (model refs, subject groups) and verify all three MaaS resources exist (`oc get maasmodelref`, `oc get maassubscription`, `oc get maasauthpolicy`)
- [REQ-022] Learner MUST be able to verify the MaaS controller generated `AuthPolicy` and `TokenRateLimitPolicy` resources for the model (`oc get authpolicy`, `oc get tokenratelimitpolicy`)
- [REQ-023] Learner MUST be able to generate a subscription-scoped API key from the *Gen AI studio → AI asset endpoints* dialog and list the models available to it via `GET ${MAAS_URL}/v1/models`
- [REQ-024] Learner MUST be able to call the model with body-based routing on `/v1/chat/completions` and receive an OpenAI-compatible JSON response
- [REQ-025] Learner SHOULD be able to observe token rate limiting (mix of `200` and `429` on rapid requests) and rejection of an invalid API key (`401 Unauthorized` or `403 Forbidden`)

## Success Metrics

`AuthPolicy` and `TokenRateLimitPolicy` are generated by the controller;
`GET /v1/models` includes `maas-llmd-demo`; chat completion requests return
OpenAI-compatible JSON; rapid requests show a `200`/`429` mix and an invalid
key is rejected with `401`/`403`.

## Risks

- A `MaaSAuthPolicy` without a `MaaSSubscription` yields `429 Too Many Requests`; a `MaaSSubscription` without a `MaaSAuthPolicy` yields `403 Forbidden`
- The temporary API key is displayed only once and expires after 1 hour
- Missing controller-generated policies require inspecting the MaaS controller logs in `redhat-aigateway-infra`

## Assumptions

- Learner has completed Module 01 (a model is deployed and published as MaaS)
